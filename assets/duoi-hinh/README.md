# Ảnh cho phần Đuổi hình bắt chữ

Đặt tên file đúng như bảng. Đuôi file có thể là `.png`, `.jpg`, `.jpeg` hoặc `.webp` (viết thường).
Nếu thiếu ảnh, game tự dùng hình vẽ sẵn.

| Đáp án | Tên file | Ảnh hiện tại | Đọc là |
|---|---|---|---|
| **TÔN GIÁO** | `ton-giao-1` | Bàn tay giơ chữ "Respect" | tôn (trọng) |
| | `ton-giao-2` | Giáo hoàng | giáo |
| **NGUỒN GỐC** | `nguon-goc-1` | Nút nguồn ⏻ | nguồn |
| | `nguon-goc-2` | Gốc cây bị chặt | gốc |
| **TÂM LÝ** | `tam-ly-1` | Bia bắn (hồng tâm) | tâm |
| | `tam-ly-2` | Einstein (nhà vật lý) | lý |
| **TÍNH LỊCH SỬ** | `tinh-lich-su-1` | Máy tính cầm tay | tính |
| | `tinh-lich-su-2` | Tờ lịch | lịch |
| | `tinh-lich-su-3` | Sách "History" | (lịch) sử |

Nếu đổi ảnh khác ý nghĩa, nhớ sửa lời giải thích (`explanation`) của câu đó trong `game.html`.
